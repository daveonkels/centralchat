# Screenshot provenance

Captured November 6, 2026 from the updated Central Chat browser demo, using only
newly authored fictional conversations. No production database, personal export,
or private server was connected to the screenshot session.

The fixtures and browser-only adapters live in the
[demo repository](https://github.com/daveonkels/central-chat-website), in
`src/data/demoConversations.ts` and `src/api/`. There are 24 fictional conversations
and 96 messages. Attachment badges reference invented filenames; no original
attachments or external media are loaded.

- `archive-dark.png`: 1440 × 1000, archive with content badges and example views.
- `reader-light.png`: 1440 × 1000, fictional espresso conversation and Markdown table.
- `commands.png`: 1440 × 1000, command palette with example saved views.
- `mobile.png`: 390 × 844, compact mobile archive with home logo.

The demo is explicitly labeled in the captures. Its saved views stay in the
browser; the self-hosted app stores saved views on the server.
